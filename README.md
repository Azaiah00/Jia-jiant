# Jia The Jiant - Official Website

A modern, SEO-optimized website for Jia The Jiant, featuring her music, modeling, and acting portfolio. Built with Next.js and deployed on Netlify.

## Features

- 🎵 Music showcase with streaming links
- 📸 Modeling portfolio
- 🎬 Acting reels and credits
- 📱 Mobile-responsive design
- 🚀 SEO optimized
- 💌 Newsletter signup with Mailchimp
- 📝 Contact form with Netlify Forms
- 🤖 AI-powered features

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Netlify
- Mailchimp Integration

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/jia-jiant.git
   cd jia-jiant
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env.local` file with the following variables:
   ```env
   MAILCHIMP_API_KEY=your_api_key
   MAILCHIMP_SERVER_PREFIX=your_server_prefix
   MAILCHIMP_LIST_ID=your_list_id
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

The site is configured for deployment on Netlify. To deploy:

1. Push your code to GitHub
2. Connect your repository to Netlify
3. Configure the following environment variables in Netlify:
   - `MAILCHIMP_API_KEY`
   - `MAILCHIMP_SERVER_PREFIX`
   - `MAILCHIMP_LIST_ID`
4. Deploy!
